# Phase 11: Collections (Completionist)

**Depends on:** 01, 06

## Goal

Let the user pull in an entire franchise/collection as a to-watch checklist
in one action, using TMDB's collection grouping.

## Requirements (EARS)

- The system SHALL support looking up a TMDB "collection" (franchise
  grouping) for a given movie.
- WHEN the user chooses to import a collection, the system SHALL create
  library placeholder entries (per Phase 06's no-file-yet support) for every
  item in the collection not already present.
- The system SHALL display a progress view per collection (e.g. "6 of 23
  watched"), derived from each item's watched state.
