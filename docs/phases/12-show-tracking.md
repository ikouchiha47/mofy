# Phase 12: Show Tracking (Binger)

**Depends on:** 02, 03, 06

## Goal

Track ongoing TV shows and surface new episodes without manual checking.

## Requirements (EARS)

- The system SHALL allow the user to subscribe to a TV show already in the
  library.
- The system SHALL periodically check TMDB for new episodes of subscribed
  shows.
- WHEN a new episode is detected, the system SHALL badge it in an "up next"
  queue across all subscribed shows.
- The system SHALL allow batch-triggering downloads (via Phase 02/03) for
  multiple missed episodes at once.
